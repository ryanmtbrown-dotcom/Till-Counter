# Till Counter v0.2.0
Offline Android till-counting application. Guided workflow: Store Charges, Gift Certificates, Vendor Coupons, Checks, Loans, cash denominations, summary.

v0.2.0 rebuilds the Android host around AppCompat + AndroidX WebViewAssetLoader, disables raw file/content access, handles Android 15/16 system-bar insets, and requires the release workflow to prove the actual first workflow screen rendered on Android 16 before publishing.
